# Naura Jewels

A premium jewelry showcase website built with HTML5.

## Overview

Naura Jewels is an elegant web platform for discovering and exploring fine jewelry collections.

**Live Website**: https://naurajewels.onrender.com/

## Getting Started

Clone the repository:

```bash
git clone https://github.com/rizwana25/naurajewels.git
cd naurajewels
```

To view locally, open `index.html` in your web browser or use a local server:

```bash
python -m http.server 8000
```

## Project Structure

- `index.html` - Main website pages
- `assets/` - Images and resources
